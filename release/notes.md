# v0.2.3

账号额度保护插件，为 Codex Proxy RS 的 OpenAI OAuth 账号分别设置 5 小时与周额度使用率上限

## 功能

- 任一已启用窗口达到或超过阈值时，停止向该账号分配新请求，已发出的请求继续完成
- 只排除触发保护的候选账号，剩余账号继续由宿主的 Smart 调度、权重与会话亲和逻辑选择
- 后台请求宿主刷新额度，新观测满足恢复条件后自动允许调度；刷新失败、观测过期或窗口数据缺失时继续保护
- 提供宿主内的管理页面，支持添加和搜索 OAuth 账号、编辑两个窗口的阈值与开关、调整观测有效期、撤销草稿和查看暂停原因
- 页面沿用宿主组件、明暗主题与窄屏布局，保存使用宿主配置及版本校验；保存成功后点击宿主右上角“刷新页面”查看新配置和状态

额度判断以宿主已经取得的观测为准，在途请求与其他客户端仍可能继续消耗额度
上游重置时间用于展示，实际恢复需要新的有效观测

## 安装与兼容

在宿主“插件管理”选择 GitHub 来源，仓库填写 `Mr-xiongyq/cpr-quota-guard`，标签填写 `v0.2.3`，选择对应平台附件
首次安装默认没有受保护账号，在插件页面添加账号并保存后开始保护

- 宿主版本范围：`>=3.35.1, <4.0.0`
- SDK 固定到 `12771aca8719ed4b23b0362b23d8d81f228190ca`，使用 RPC v7、management v2、页面桥 v2、scheduler v3、maintenance v1、command_line v1
- Linux x86_64 安装包要求 glibc 2.28+，不适用于 Alpine/musl
- 同时提供 macOS arm64 安装包，每个安装包附带 `.sha256` 校验文件

完整配置与使用说明见 [README](https://github.com/Mr-xiongyq/cpr-quota-guard/tree/v0.2.3#readme)
